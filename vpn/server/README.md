# Сервер

`install.sh` ставит VPN на VPS (Ubuntu/Debian) одной командой:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/andty190212-afk/claude/main/vpn/server/install.sh)
```

После установки на сервере появляется команда `vpn`:
`add`, `del`, `show`, `list`, `status`, `exe` (Windows), `ios` (iPhone).

Подробная инструкция — в [../README.md](../README.md).
