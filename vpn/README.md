# Свой VPN за ~$3 в месяц

Протокол **VLESS + Reality** (Xray). Трафик выглядит как обычный HTTPS к крупному сайту,
поэтому работает даже там, где WireGuard и OpenVPN блокируют.

## Установка в 1 команду

Арендуй VPS с **Ubuntu 22.04/24.04**, зайди на него (`ssh root@IP`) и вставь:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/andty190212-afk/claude/claude/zealous-bell-wylfdx/vpn/install.sh)
```

Через ~2 минуты появится QR-код. Отсканируй его в приложении — готово.

**Ещё проще (вообще без SSH):** у многих хостеров при создании сервера есть поле
*«User data» / «Cloud-init» / «Startup script»*. Вставь туда:

```bash
#!/bin/bash
bash <(curl -fsSL https://raw.githubusercontent.com/andty190212-afk/claude/claude/zealous-bell-wylfdx/vpn/install.sh)
```

Сервер настроится сам при запуске. Ссылку потом посмотри командой `vpn show my-vpn`
или в файле `/root/vpn-link.txt`.

## Windows: MyVPN.exe — подключение в 1 клик

Готовый клиент, ничего настраивать не надо: **двойной клик → VPN работает,
закрыл окно → выключился.**

**Вариант А — личный exe со ссылкой внутри (удобнее всего для друзей).** На сервере:

```bash
vpn exe vasya
```

Получится `/root/MyVPN-vasya.exe` со вшитой ссылкой. Скачай его к себе
(`scp root@IP:/root/MyVPN-vasya.exe .`) и отправь человеку в Telegram.
Ему нужно только запустить файл.

**Вариант Б — общий exe.** Скачай
[MyVPN.exe](https://github.com/andty190212-afk/claude/releases/download/client-latest/MyVPN.exe),
запусти и один раз вставь ссылку `vless://` — она запомнится.
(Или положи рядом файл `vpn.txt` со ссылкой.)

Как это работает: внутри exe — ядро Xray. Оно поднимает локальный прокси
`127.0.0.1:10809` и включает его в настройках Windows, поэтому через VPN идут
браузеры и большинство программ. При закрытии окна прокси выключается.
Если программа была убита аварийно и интернет пропал — запусти `MyVPN.exe --off`.

> Windows может показать «Windows защитила ваш компьютер» — exe не подписан.
> Нажми «Подробнее» → «Выполнить в любом случае».

Каждый новый пуш в `vpn/client/` автоматически пересобирает exe (GitHub Actions →
релиз `client-latest`).

## Защита (включается автоматически)

| Что | Зачем |
|---|---|
| Reality + шифрование X25519 | трафик не отличить от обычного сайта, нельзя расшифровать |
| Файрвол UFW | наружу открыты только SSH и порт VPN, всё остальное закрыто |
| Лимит на SSH + fail2ban | бан IP на 1 час после 5 неудачных попыток входа |
| Автообновления безопасности | Ubuntu сама ставит патчи |
| Еженедельное обновление Xray | всегда свежая версия |
| Без логов посещений | `access: none` — сервер не пишет, куда ты ходишь |
| Блок торрентов и SMTP | чтобы хостер не забанил сервер за жалобы/спам |
| Блок локальных сетей | через VPN нельзя достучаться до внутренних адресов сервера |
| Ключи доступны только root | `chmod 600` |

**Дополнительно (рекомендую):** настрой вход по SSH-ключу, а потом запусти
`HARDEN_SSH=1 bash <(curl ...)` — пароль для SSH отключится совсем.
Скрипт не даст это сделать, если ключа нет, чтобы ты не потерял доступ.

## Управление

```bash
vpn add phone     # новое устройство / друг — своя ссылка и QR
vpn del phone     # отключить
vpn show phone    # показать ссылку снова
vpn list          # все пользователи
vpn exe laptop    # готовый MyVPN-laptop.exe для Windows
vpn status        # состояние VPN, файрвола, fail2ban
```

Давай каждому устройству свою ссылку — если одну утечёт, просто удали её.

## Если не работает

- `vpn status`, `journalctl -u xray -n 50` — логи.
- Проверь firewall в панели хостера: должен быть открыт порт 443/TCP.
- Сменить сайт маскировки: удали `/usr/local/etc/xray/vpn.env` и запусти установку с `SNI=www.apple.com`.
